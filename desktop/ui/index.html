Данные и версии

Реле — самостоятельная программа. Здесь указан идентификатор совместимости с бэкендом Codex, а не установленная версия Codex CLI.

Без окна

Запусти praxis-relay-headless.exe serve --headless. Ему не нужны Tauri, WebView или системный трей.

Другой терминал управляет тем же процессом:
praxis-relay-headless.exe status
praxis-relay-headless.exe switch secondary
praxis-relay-headless.exe logout all
