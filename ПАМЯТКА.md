# praxis-relay 1.2.0

- `praxis-relay-desktop.exe` — приложение Tauri. Аккаунты, квоты, вход, выход,
  переключение и настройки находятся в окне. Сворачивание и крестик скрывают
  окно в трей возле часов. Выход из программы — через меню этой иконки.
- `praxis-relay-headless.exe serve --headless` — сервер без окна, трея и WebView.
  Команды управления запускаются из второго терминала.

Для входа по коду нажми «Войти по коду»: открой показанную страницу на любом
устройстве и введи одноразовый код. Код действует до 15 минут; вход можно отменить.
В ChatGPT должен быть включён вход по коду (настройки безопасности или разрешения
рабочего пространства). Python и проброс localhost для этого способа не нужны.

Вход через браузер сохранён отдельно; только ему нужен Python 3.10+.
Заглушка Microsoft Store больше не принимается за Python. При необходимости
укажи путь к настоящему интерпретатору в `RELAY_PYTHON`.

Запусти приложение, войди в ChatGPT и нажми «Запустить API». В клиенте укажи
Base URL из окна: по умолчанию `http://127.0.0.1:5011/v1`. API key скопируй
из карточки подключения. При первом запуске создаётся случайный ключ из
47 символов с префиксом `sk-`. Он хранится в `local_auth/api-key.txt`, одинаков
для Tauri и headless и сохраняется после перезапуска, входа и выхода из аккаунтов.
`RELAY_API_KEY` явно задаёт другой ключ для встраивания. Строка `relay` больше
не используется; запросы генерации без правильного ключа отклоняются.

Проверка квот не генерирует ответ модели и не выбирает другой аккаунт.
Переключение действует для новых запросов; начатый ответ может завершиться.
Дополнительные квоты моделей не переносятся и не объединяются.

Оба exe положи в одну папку, но запускай один серверный режим за раз.
Данные находятся в `local_auth` рядом с программой; `RELAY_AUTH_DIR` задаёт
другое хранилище. Реле не берёт вход из `.codex` или `.opencode` и не изменяет
авторизацию этих программ. До установки новых учётных данных неудачный или
отменённый вход сохраняет прежний аккаунт. После установки проверенных новых
данных поздняя отмена или ошибка сохранения их не откатывает. Выход удаляет
вход выбранного слота именно в этом реле.

```text
praxis-relay-headless.exe status
praxis-relay-headless.exe login primary --device-auth
praxis-relay-headless.exe login primary
praxis-relay-headless.exe login secondary
praxis-relay-headless.exe switch secondary
praxis-relay-headless.exe limits primary
praxis-relay-headless.exe logout primary
praxis-relay-headless.exe logout all
praxis-relay-headless.exe cancel_login
praxis-relay-headless.exe stop
```

Для удалённого сервера используй `login --device-auth`: подтверждение можно
пройти на другом устройстве. Только старый вход через браузер требует
проброса callback-порта 1455. Серверные запросы работают без браузера.
Для службы выбирай отдельную доступную для записи папку `RELAY_AUTH_DIR`.

Версия протокола Codex в настройках — идентификатор совместимости с бэкендом.
Само реле — отдельная программа, а не установленный Codex CLI.
Окно без системной рамки. Крестик и сворачивание убирают его в трей;
Ctrl+Q завершает программу. Ctrl+1/2/3 открывают разделы, Ctrl+, — настройки.

В настройках доступны бумага, акценты, светлая/тёмная/системная тема,
масштаб, плотность, почерк, фактура и анимация. Там же — свои названия
подписок, обновление квот, API при запуске, запуск в трее, порт, модель,
reasoning, инструкции и параллельные инструменты. Изменения сохраняются
сразу в local_auth/settings.json. Для новых параметров API окно покажет,
когда нужен перезапуск; смена оформления его не требует.

Headless принимает частичный JSON: `praxis-relay-headless.exe configure patch.json`.
Поля, которых нет в patch.json, сохраняются. Переменные запуска имеют приоритет.
Сборка, пример настроек и полный API: [README.md](README.md).
