# Реле: подписка ChatGPT как локальный API (Windows)

Реле — это маленькая программа, которая превращает твою **подписку ChatGPT**
(Plus/Pro) в обычный OpenAI-совместимый API у тебя на компьютере. Никакого
API-ключа OpenAI и API-биллинга не нужно: платишь только за подписку, а твой
агент (Hermes, OpenClaw, свой скрипт — что угодно, умеющее OpenAI API) ходит
на `http://127.0.0.1:5011`.

Честная оговорка: это неофициальный мост (реле говорит с бэкендом ChatGPT по
протоколу Codex). OpenAI такой способ не благословлял — используешь свою
подписку на свой страх. Наружу реле не торчит: слушает только твой компьютер.

## Что понадобится

- Windows 10/11;
- подписка ChatGPT (Plus достаточно);
- Python 3 — нужен **только на минуту логина** (шаг 2), дальше не используется.
  Если нет: `winget install Python.Python.3.12` в терминале, либо с python.org
  (при установке отметь галочку «Add python.exe to PATH»);
- файл `praxis-relay.exe`.

## Запуск за три шага

**Шаг 1. Папка.** Положи `praxis-relay.exe` в отдельную папку, например
`C:\relay`. Рядом с ним появятся папки `local_auth` (твой вход в аккаунт) и
`logs` (журналы).

Если Windows SmartScreen ругнётся при первом запуске: «Подробнее» → «Выполнить
в любом случае». Это самосборный exe без подписи издателя, отсюда и окно.

**Шаг 2. Логин (один раз).** Запусти `praxis-relay.exe`, в меню нажми `3`
(Login) и Enter. Откроется браузер — войди в аккаунт ChatGPT, на котором
подписка. Если в браузере залогинено несколько аккаунтов, лучше открыть ссылку
в приватном окне, иначе он может молча взять не тот. Дождись в консоли
`Login completed!`.

Если браузер после логина показал ошибку, а в консоли всё равно
`Login completed!` — верь консоли, логин прошёл.

**Шаг 3. Сервер.** В меню нажми `1` (Run server). Увидишь
`Server is running` — готово. Окно не закрывай: закрыл окно — выключил реле.

Проверка: открой в браузере `http://127.0.0.1:5011/health` — должно ответить
`"status":"healthy"`.

## Подключаем агента

В любом OpenAI-совместимом клиенте:

| Поле | Значение |
|---|---|
| base_url | `http://127.0.0.1:5011/v1` (без `/v1` тоже работает) |
| api_key | любая строка, например `relay` — она не проверяется |
| model | `gpt-5.6-terra` (см. список ниже) |

Пример на Python:

```python
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:5011/v1", api_key="relay")
r = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[{"role": "user", "content": "привет!"}],
)
print(r.choices[0].message.content)
```

Работают оба режима: обычный запрос и стриминг (`stream=True`). Картинки на
вход (vision) и tool calls тоже работают.

**Модели:** `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`, `gpt-5.5`,
`gpt-5.4`, `gpt-5.4-mini`. Что реально отдаёт бэкенд, зависит от твоего плана
подписки: terra/luna на Plus живут спокойно, самая тяжёлая sol на дешёвых
планах может возвращать пустоту. Полный список: `http://127.0.0.1:5011/v1/models`.

## Если что-то не так

- **«no usable ChatGPT account profile» при запуске сервера** — ты ещё не
  логинился (или логин протух). Сначала пункт `3`, потом `1`.
- **В ответе пришло «…rejected the credentials (401). Sign in again…»** —
  токен умер. Меню `3`, перелогин, и всё оживёт (сервер можно не перезапускать).
- **Порт 5011 занят.** Меню `6` покажет, что живёт на портах 5011–5020.
  Либо убей старое реле через меню `2`, либо запусти на другом порту:
  в PowerShell `$env:RELAY_PORT="5013"; .\praxis-relay.exe` (и поменяй порт
  в base_url агента).
- **Упёрся в лимит.** Это лимиты твоей подписки ChatGPT (примерно 5-часовые
  окна + недельный потолок). Реле честно напишет это в ответе. Остатки можно
  смотреть на `http://127.0.0.1:5011/v1/limits`. Лечится только ожиданием.
- **«Python 3 was not found» на логине** — поставь Python (см. «Что
  понадобится») или укажи путь напрямую:
  `$env:RELAY_PYTHON="C:\путь\до\python.exe"`.

## Безопасность

- Реле слушает **только** `127.0.0.1` — с других компьютеров к нему не
  подключиться, наружу ничего не открывается.
- Папка `local_auth` — это вход в твой аккаунт ChatGPT. **Никому не отправляй
  её содержимое** и не выкладывай. Удалил папку — разлогинился.
- Реле не трогает твой обычный Codex/`~/.codex`: у него своя авторизация в
  своей папке.

## Продвинутое (можно не читать)

Настройки через переменные окружения (задавать перед запуском):

- `RELAY_PORT` — порт вместо 5011;
- `RELAY_AUTH_DIR` — где держать авторизацию (по умолчанию `local_auth` рядом
  с exe);
- `RELAY_PYTHON` — путь к python.exe для логина;
- `RELAY_REASONING_EFFORT` — глубина размышления по умолчанию
  (`none`/`low`/`medium`/`high`; из коробки `none` — быстрее и дешевле по
  лимитам); клиент может передать свою в поле `reasoning_effort` запроса;
- `RELAY_LOG_DIR` — куда писать журналы.

Два аккаунта с автопереключением при исчерпании квоты: положи авторизации в
`local_auth\accounts\primary\auth.json` и `local_auth\accounts\secondary\auth.json`
(проще всего: залогиниться, переложить готовый `auth.json` в
`accounts\primary\`, перелогиниться под вторым аккаунтом, переложить в
`accounts\secondary\`). Посмотреть слоты: `GET /v1/account`; переключить руками:
`POST /v1/account/switch` с телом `{"slot":"secondary"}`.
